# Face Attendance System

## Overview

A Face Recognition Attendance System built using Flask, OpenCV, SQLite, and LBPH Face Recognition.

## Features

- Admin Login
- Admin Registration
- Student Registration
- Face Image Capture
- Face Recognition Attendance
- Attendance Records
- Export Attendance CSV
- Student Management
- Responsive Bootstrap UI

## Technologies

- Python
- Flask
- OpenCV
- SQLite
- HTML
- CSS
- Bootstrap 5
- JavaScript

## Installation

```bash
git clone <repository-url>
cd Face-Attendance-System

pip install -r requirements.txt

python app.py
```
